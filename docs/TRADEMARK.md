# Trademark and Brand Policy

This document explains how the QualCoder name, logo, and branding may be used. QualCoder is a volunteer community project; the aim of this policy is to keep the project identifiable and trustworthy, not to restrict legitimate uses.

## 1. What this policy covers

- The name **QualCoder**
- The QualCoder logo (`qualcoder.png` and `QC_Logo.ico` in the repository root)
- Project branding on [qualcoder.org](https://qualcoder.org) and official project channels

## 2. Ownership

The QualCoder name and logo are project marks of the QualCoder project, used on the basis of common-law trademark rights (™, unregistered). Copyright in the logo and documentation is held by the project contributors.

## 3. Uses that never require permission

- **Nominative use** — referring to QualCoder by name in articles, papers, theses, courses, or conference talks. Please cite the version you used, following `CITATION.cff` in the repository root.
- **Screenshots** of the application in teaching, research, or publications.
- **Redistributing unmodified official releases**, such as Linux packages or mirrors, provided the release version is clearly identified and the redistribution is not presented as made by the project.
- **Forking the code** under the LGPL v3 license. Code rights are governed by the license; see §4 for naming of modified distributions.

## 4. Uses that require permission

Please open a GitHub issue first if you want to:

- Distribute a **modified version** under the name "QualCoder". Forks and downstream builds must be clearly identified as such (for example, "QualCoder — XYZ build") and use a modified logo so users are not misled about the origin of the software.
- Use the **QualCoder logo** in a commercial service, training, or product.
- Create merchandise or promotional material featuring the name or logo.
- Register a domain name or social media account that uses the project name.

Requests are handled by the maintainers by consensus, as described in [`GOVERNANCE.md`](https://github.com/ccbogel/QualCoder/blob/master/docs/GOVERNANCE.md).

## 5. Prohibited uses

- Any use that suggests endorsement by the QualCoder project or its maintainers without written agreement.
- Presenting unofficial binaries as official. Official QualCoder binaries are published **only** on the [GitHub Releases page](https://github.com/ccbogel/QualCoder/releases) and the [Codeberg mirror](https://codeberg.org/qualcoder).
- Using the name or logo to imply that the project provides commercial support, hosting, or certification.

## 6. Future stewardship

If QualCoder joins a foundation (for example Apereo incubation), stewardship of the name and logo may be transferred to the host organisation. This document would then be updated to point to the host's trademark policy.

## 7. Contact

Open an issue on the [QualCoder repository](https://github.com/ccbogel/QualCoder/issues) with the label `trademark`, or contact the project lead via the email in [`CODE_OF_CONDUCT.md`](https://github.com/ccbogel/QualCoder/blob/master/docs/CODE_OF_CONDUCT.md).
