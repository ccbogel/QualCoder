## Systematically compare two codes

### Objective
Compare two conceptually similar or potentially overlapping codes in a way that clarifies their respective analytical profiles, identifies clear cases, borderline cases, and likely miscoded cases, and refines the inclusion and exclusion criteria for future coding.

1. Review the source material

For each code, examine:
- Code name
- Code memo
- The coded segments

If possible:
- First read a broad selection from different interviews
- If there are very few segments, state clearly that the assessment is preliminary

2. Formulate the guiding analytical question
Briefly note the following for each of the two codes:
- What exactly does this code highlight or bring into focus in the empirical data?
- What particular view or perspective does it offer on the empirical data?
- How does it differ from the other code?

3. Classify coded segments systematically
Place all reviewed segments for each code into one of three groups:

a) Clear case
The segment clearly fits the code without significant doubt.
Criterion:
The meaning indicated by the memo or code name is present in the material, either explicitly or through clear implication.

b) Borderline case
The segment partly fits, but another code would also be plausible.
Criteria:
Multiple interpretations are possible.
The code captures something relevant, but not necessarily the primary meaning of the passage.

c) Likely candidate for recoding / critical review
Based on the current assessment, the segment does not appear to fit the code well.
Criteria:
The central meaning of the passage clearly lies elsewhere.
The existing coding appears too broad, imprecise, or misleading.

4. Give a brief justification for each segment
For each classified segment, briefly note:
- Why is it a clear case, borderline case, or questionable case?
- What is the central feature of the passage?
- What alternative would be plausible?
Keep the justification concise, but always ground it in the material.

5. Write a comparative analysis
At the end, distinguish the two codes directly from one another:
- What does Code A capture that Code B does not?
- Where do they overlap?
- Where is there a risk of confusing them?
- Which code is currently narrower and more precise, and which is broader and less precise?
- What blind spots arise if only one of the two codes is used?

The report should ideally use the following structure:

5. Analytical value

6. Implications for future coding
Preliminary inclusion and exclusion criteria
Guidance on double-coding
Open questions

7. Methodological rules
- Do not recode prematurely; conduct an analytical review first
- Allow double-coding when two aspects are genuinely central at the same time
- Do not respond only to individual words; consider the broader meaning and clearly distinguish between:
  - Empirical statement
  - Interpretation
  - Coding decision
- If only limited data are available, explicitly state that the assessment is preliminary
